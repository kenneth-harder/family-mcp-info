Private tools for
everyday planning.

Family MCP connects a private household assistant to selected services, so its users can manage everyday tasks through chat.

This is an information site. It does not provide access to the assistant, connect to your Google account, or display calendar or household records.

Calendar, through conversation

The Google Calendar connection can list calendars, find events in a date range, and preview and create events on calendars the connected user owns.

It supports timed events, all-day events and eligible Out of office events. Out of office events never automatically decline invitations. The current integration has no event editing or deletion tools.

Separate accounts, explicit actions

Each Google account is connected separately. Users choose the account and calendar for an action, review the event details and authorize creation.

The assistant also supports private household records and shopping tasks through separate modules. Connecting Google Calendar does not connect those other services.

Why Google access is requested

Calendar-list access lets the assistant identify the correct calendar. Event access lets it find and create events on calendars you own. Google's permission groups creation with modification and deletion, even though Family MCP currently exposes only reading and creation.

The Google Calendar connection does not request Gmail, Drive, contacts or calendar-sharing permissions.

Where information goes

The application runs on a privately managed Raspberry Pi. Account credentials and saved event previews are stored there, outside the public website and source releases. Calendar details returned by the tools pass through the configured ChatGPT connection so the assistant can respond to the user's request.

Read the privacy policy for the data accessed, storage, service providers, retention and deletion controls.

About this project

Family MCP is operated by Kenneth Harder for personal and invited household use. It is not a public registration service or a Google product. This website publishes information about the project; the assistant and its records remain private.

For general technical questions, use the public information repository. Do not post calendar details, account credentials or other private information there. Invited users should contact the operator through their existing private contact channel for account or data requests.
