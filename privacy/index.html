Family MCP

Privacy policy

Effective date: 27 October 2026

This policy covers the privately operated Family MCP assistant and this public information website. Kenneth Harder operates the assistant for personal and invited household use.

Information accessed

When a user connects Google Calendar, Family MCP uses the authorized account to access calendar identifiers, names, primary-calendar status, time zones and access roles. For event searches and creation, it processes event titles, descriptions, locations, dates and times, event types, statuses, identifiers, Google Calendar links and Out of office settings.

The application also receives the event details supplied by the user. Google OAuth credentials, including refresh tokens, are used to maintain the connection without asking the user to sign in for every request.

The requested Google permissions are calendar.calendarlist.readonly and calendar.events.owned. The latter permits Google event modification and deletion as well as reading and creation. The current Family MCP tools do not expose event editing or deletion. The Calendar connection does not request access to Gmail, Drive or contacts.

How information is used

Google data is used to identify calendars, answer the user's calendar queries, preview requested events, create authorized events and check previous creation attempts to avoid duplicates. Out of office events created by this integration do not automatically decline invitations.

The operator does not sell Google user data, use it for advertising, or use it to train generalized AI models. Family MCP's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Storage and retention

OAuth credentials and saved event previews are stored on the operator's privately managed Raspberry Pi, separately from public source files and application releases. Access is restricted using operating-system permissions. Authorized administrators of that system can access its stored records.

Saved previews contain the selected account alias and calendar, event details, a creation identifier, timestamps and attempt status. A preview's creation permission expires after 30 minutes, but the saved file is not automatically deleted. Preview files remain until the operator removes them. Credentials remain until removed or replaced. Private backups, if made by the operator, may retain copies until those backups are removed.

Search responses are processed to answer requests; the Calendar module does not maintain a separate calendar-search archive. Tool results can remain in the user's chat history. Events created in Google Calendar remain there until deleted using Google Calendar or another authorized service.

Service providers and sharing

  • Google: authenticates connected accounts and processes Calendar API requests. Google's services are governed by Google's Privacy Policy.
  • OpenAI / ChatGPT: event details in user requests and Calendar tool results are transmitted through the configured private connection to ChatGPT to process requests and generate responses. Conversation retention and handling also depend on the user's OpenAI product, account settings and OpenAI's Privacy Policy. OAuth credential files are not exposed by the Calendar tools.
  • GitHub Pages: hosts this public information website. The site includes no analytics scripts, advertising, contact forms or application sign-in. GitHub may collect technical visitor information, including IP addresses, for hosting and security under the GitHub Privacy Statement. Calendar data and OAuth credentials are not published to this site.

People who can access the connected ChatGPT account or its conversations may be able to see returned information. Users should only connect accounts and request information they are authorized to access. The operator may access private application data to provide requested support, maintain the service or respond to a legal obligation.

Disconnecting and deleting data

Users can revoke Family MCP's Google access through Google Account connections. Revocation prevents further authorized access but does not erase saved local previews, existing Google events or previous chat messages.

Invited users can ask the operator through their existing private contact channel to remove local credentials and saved previews, including applicable private backups. Chat history must be managed through the relevant ChatGPT controls; existing calendar events can be managed in Google Calendar. No automatic deletion deadline is promised.

Other household modules

Separately enabled household and shopping tools process user-supplied household records, shopping requests and connected-service results for the requested task. These records are stored privately and relevant tool results can appear in ChatGPT. Google authorization does not grant access to those services. This website does not collect household records or offer public access to them.

Contact and changes

The operator is Kenneth Harder (GitHub profile). Invited users should use their existing private contact channel for privacy and deletion requests. General, non-sensitive questions can be raised in the public information repository; do not include private data or credentials.

This policy will be updated when the application's data practices change. Changes requiring additional authorization will be presented before the new access or use begins.
